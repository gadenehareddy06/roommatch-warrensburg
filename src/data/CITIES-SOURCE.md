# U.S. locations

Source: U.S. Census Bureau, 2025 National Places Gazetteer.
https://www.census.gov/geographies/reference-files/2025/geo/gazetter-file.html

The bundled directory contains 31,847 Census city/place and state pairs across all 50 states and Washington, DC, plus the common Honolulu alias for Urban Honolulu. It includes incorporated places and census-designated places; it is not a directory of every informal neighborhood or postal alias. Puerto Rico and other territories are outside this U.S.-states selector.

Names have Census legal suffixes removed for display. The directory is bundled locally so searches need no API key or external geocoding requests.

Nationwide sample homes are entirely fictional. Their illustrative prices are not market estimates. Sample homes are generated only in demo mode; a connected Supabase project shows actual database listings and empty states instead.
